Projet Final - Gestion de Bibliothèque
Description

Application console en C permettant de gérer une bibliothèque de livres.

Fonctionnalités :

Ajouter un livre
Afficher les livres
Rechercher un livre
Emprunter ou rendre un livre
Supprimer un livre
Sauvegarder les données dans un fichier

Compilation
make

Exécution
./app

Nettoyage
make clean
